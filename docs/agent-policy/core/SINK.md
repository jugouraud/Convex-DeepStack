## SINK

- CORE.SINK1 M Bind SQL values; choose identifiers/sort/query structure from fixed mappings. Build explicit permitted filters; never pass raw request objects as ORM writes/queries.
- CORE.SINK2 M Use context-aware escaping/text APIs; keep templates controlled; sanitize allowed rich HTML with maintained tools; restrict active URL schemes. CSP is supplemental.
- CORE.SINK3 M Prefer libraries over OS commands; otherwise fixed executable+argv, validate options, tool-supported --, bounded environment/workdir/runtime/output and least privilege.
- CORE.SINK4 M Use authorized server-generated storage IDs; contain paths including symlinks/archive links/platform forms. No string-prefix checks; prevent check/open races; use secure temp facilities.
- CORE.SINK5 M Validate needed upload formats with intended parsers; distrust MIME/extensions/signatures alone. Bound expansion/entries/dimensions/work; private quarantine, isolated parsing, deliberate safe serving.
- CORE.SINK6 M Prefer mapped IDs. For user-influenced URLs enforce scheme/port/destination on actual IPv4/IPv6 connections incl DNS/retries/redirects; no forbidden networks/ambient credentials; bound responses, egress controls as appropriate.
